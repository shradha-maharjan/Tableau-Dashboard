# Airways Customer Experience Dashboard

## Overview
This project presents an **interactive Tableau dashboard** analyzing **customer satisfaction and service quality** for British Airways using passenger review data. The dashboard helps stakeholders understand how customer experience varies across **time, geography, aircraft types, traveler segments, and service dimensions**.

The goal is to demonstrate how **business metrics, KPI design, and data visualization** can support data-driven decision-making.


## Business Objective
- Monitor overall customer satisfaction and key service metrics
- Identify trends and patterns in passenger experience over time
- Compare performance across aircraft models and regions
- Highlight opportunities for service and operational improvements


## Key Metrics
The dashboard tracks the following KPIs:
- Average Overall Rating  
- Cabin Staff Service  
- Entertainment  
- Food & Beverages  
- Ground Service  
- Seat Comfort  
- Value for Money  

These KPIs provide a quick snapshot of customer experience performance.

## Trend Analysis
- Monthly trend analysis from **2016 to 2024**
- Highlights periods of improvement and decline
- Supports correlation with operational or service changes


## Geographic Analysis
- Interactive world map showing **average ratings by country**
- Identifies regional differences in customer satisfaction
- Useful for targeting improvement efforts by market


## Aircraft-Level Insights
- Comparison of average ratings by **aircraft model**
- Displays **number of reviews** alongside ratings for context
- Helps avoid misinterpretation of low-volume data


## Interactivity & Filters
Users can explore the data using filters for:
- Metric type (overall rating or service categories)
- Traveler type (business, leisure, family, solo)
- Seat class (economy, business, first, premium economy)
- Aircraft type
- Continent
- Time range

This supports both **executive-level summaries** and **detailed analysis**.


## Insights
- Customer satisfaction varies by aircraft type and seat class
- Certain service categories consistently underperform
- Trends over time emphasize the need for continuous monitoring
- High-volume aircraft have greater impact on overall ratings


## Tools & Skills
- Tableau (dashboard design and interactivity)
- KPI definition and metric consistency
- Trend and segmentation analysis
- Data storytelling for business users


## Key Takeaway
This project showcases my ability to build **KPI-driven BI dashboards** that translate complex data into clear, actionable insights for decision-makers.
